# Supersore-EDA-Analysis
Superstore Sales &amp; Profit Analysis is an exploratory data analysis project focused on understanding sales performance, profitability, customers, products, categories, regions, and shipping patterns.  The project uses Python, Pandas, NumPy, Matplotlib, and Seaborn to clean, analyze, and visualize the Superstore dataset. 
🎯 Objectives
Understand the structure and quality of the dataset
Identify missing values, duplicates, and data inconsistencies
Analyze sales and profit trends
Identify top and bottom-performing products
Compare category and sub-category performance
Analyze customer and regional performance
Understand the relationship between discount and profit
Detect unusual values and outliers
Generate meaningful business insights

🗂️ Dataset

The dataset contains 9,994 records and 21 columns.
